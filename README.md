# Project Overview
This project focuses on analyzing and visualizing sales data from an E-Commerce business using Python, Pandas, NumPy, and Matplotlib.
The goal of this analysis is to identify sales trends, regional performance, profit patterns, and the impact of discounts on customer orders and profitability.

# Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
